# Examples

| Example | What it is | Use it to |
| :--- | :--- | :--- |
| [`playground/`](playground/README.md) | Two runnable pages over a mock API, plain ES modules, `npm run example` | click every option, and find the file behind each panel |
| [`react-remote/App.tsx`](react-remote/App.tsx) | Every feature as TypeScript and JSX, the way an application writes it, type-checked with the package | copy code into a project |

Both use the package the way a project that ran `npm install apsw-gridwright` does. The playground
loads the same exports from `dist/` because it has no bundler; its README has
[the translation table](playground/README.md#from-the-playground-to-your-application).

Start with the playground's [I want to…](playground/README.md#i-want-to) table.
