# API surface contract: agent compatibility

> Nothing locks this file; it holds because agents hold it. An implementation that finds this wrong
> stops and returns to planning; it does not edit this file.

## Semver classification

**none.** No export, type, default or file in the published tarball changes. `scripts/`, `.agents/`,
`specs/` and the agent instruction files are not in `files`.

## Exports added, changed or removed

None.

## Repository contract: `workflow.ai.yml`

The surface here is the workflow file, which scripts and agents read. Proposed, to be confirmed
after T1:

```yaml
# Every fact carries its kind and source, like research.md. check-workflow.mjs reads `loads` and
# `max_chars` to enforce AC-02; the rest is documentation for the matrix.
agents:
  - id: antigravity
    loads: ["AGENTS.md", "GEMINI.md", ".agents/rules/*.md"]
    skills: ".agents/skills"
    max_chars: 12000
    source: "https://antigravity.google/docs/rules-workflows/"
    verified: "documented 2026-09-15"
  - id: claude_code
    loads: ["CLAUDE.md", "AGENTS.md (imported)"]
    skills: ".claude/skills"
    max_chars: 0          # no documented limit; 0 means none enforced
    verified: "tested 2026-09-15"
```

Changed keys:

| Key | Change |
| :--- | :--- |
| `stages[].guidance`, `tracks[].guidance` | may point at `.agents/skills/<name>/SKILL.md`; may not point into `.agents/workflows/` |
| `governance.precedence` | the `GEMINI.md` entry stops claiming it outranks `AGENTS.md` in Antigravity |
